# Letter Catcher

A free typing reflex game. Letters fly in from the left, right and top of the screen; type each one before it escapes.

- Levels 1-2: home row (A S D F J K L)
- Levels 3-5: adds E I R U T N O
- Level 6+: all 26 letters
- New level every 6 catches; round ends after 60 seconds or 5 missed letters

Single file (`index.html`), no dependencies, no build step. Open it in a browser to play.

## Run on GitHub Pages

1. Create a new repository on GitHub and upload `index.html` and `README.md`.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. Your game will be live at `https://<username>.github.io/<repo>/`.
